Phòng Flash

Chơi game .swf ngay trên trình duyệt, chạy bằng Ruffle.

    Chưa có game nào trong thư viện. Thêm file vào thư mục games/ và khai báo trong games/games.json.

    Máy yếu RAM? Chọn chất lượng Thấp, và bấm “Thoát game” mỗi khi chơi xong để giải phóng bộ nhớ.

    Chưa có game nào đang chạy Chọn game ở thư viện, hoặc kéo file .swf thả vào khung này.
    Sẵn sàng

    Đổi chất lượng sẽ có hiệu lực ở lần tải game tiếp theo. File mở từ máy chỉ chạy trong trình duyệt của bạn, không bị tải lên đâu cả.
